# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Protector hardens Android applications. Please **do not** open public GitHub
issues for security vulnerabilities.

Prefer one of:

1. [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories)
   for this repository (private vulnerability report), when enabled; or
2. Email maintainers privately:

   **`xopJack@163.com`**

Include:

- Affected version / commit
- Reproduction steps or a minimal PoC
- Impact assessment (crash, bypass, disclosure, etc.)

We will acknowledge receipt when possible and coordinate a fix and disclosure
timeline. Please give maintainers reasonable time before public disclosure.
